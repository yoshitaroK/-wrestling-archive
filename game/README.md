# レスリング人生 〜オリンピックへの道〜

`index.html` 1ファイルで動くスマホ向けの育成ゲームです(仕様は `wrestling-life-spec.md`)。
公開後のURL: https://japanwrestlingchannel.com/game/

## ファイル
- `index.html` … ゲーム本体。計算部分(`==LOGIC START==`〜`==LOGIC END==`)と画面部分に分けてあります。
- `sim.js` … バランス確認用の自動プレイ。`node game/sim.js 5000` で5000人ぶん遊んで金メダル率などを表示します。
- `wrestling-life-spec.md` … 仕様書。

## バランス(仕様書の初期案から変えたところ)
初期案のままだと、ふつうに遊ぶだけで24歳の金メダル率が約8割になり簡単すぎたため、
`index.html` の `BAL`(バランス調整用のつまみ)で次のように調整しました。

| つまみ | 初期案 | いま | 意味 |
|---|---|---|---|
| gainScale | 1.0 | 0.88 | 練習の上昇量の全体倍率 |
| capDiv | 150 | 120 | 伸びにくさ `1 − 現在値/capDiv` |
| declineSS | 1.5 | 4 | 31歳以降のスタミナ・スピードの衰え(毎年) |
| declineOther | 0 | 2 | 31歳以降のほかの3能力の衰え(毎年) |
| olyStep | 1.5 | 5.5 | オリンピックの相手が4年ごとに強くなる量 |
| trialsStep | 0 | 5 | 代表選考会の相手が4年ごとに強くなる量 |
| topBonus | 0 | 3 | 代表選考会とオリンピックの相手に足す強さ |

標準的な遊び方(疲労を管理しながら低い能力を伸ばし、大会前は休む)での結果(5000回):
金メダル率 約22%(24歳 3% / 28歳 14% / 32歳 5% / 36歳 ほぼ0%)。
(最初は47%だったが、遊んだ感想「もっと難しくていい」を受けて topBonus=3 を追加)
休まず練習し続けると 3% 前後まで下がります。

つまみは `node game/sim.js 3000 gainScale=0.9 olyStep=5` のように、ファイルを書き換えずに試せます。

## 仕様書と少し違うところ
- 世界選手権・オリンピックの決勝の相手はライバルではなく外国の「世界王者」(ライバルは日本人なので)。
- 「良い師匠」は出会ったその年(春・夏・秋の3回)の成長が×1.3。
- オリンピックで準決勝に負けると3位決定戦(勝てば銅、負ければ4位)。それより前に負けたらメダルなし。
- 生まれる子の性別は決めず「赤ちゃん」と表示しています。

## あとから追加したもの
- **U15アジア選手権**(15歳): 全国中学大会で優勝すると、同じ冬に出場できる。相手はアジアの国の架空の選手、全4試合、強さは全中+4。決勝の相手は「アジア王者」。
  標準的な遊び方だと、全中優勝 約56% → アジア優勝はそのうち約33%。
- **金メダルの特別エンディング**: 決勝の瞬間 → 表彰式 → ライバルの言葉 → 地元への凱旋 → その後と称号 → 成績まとめ、の順に「つぎへ」で進む。
  決勝のスコアや決まり方、ライバルとの勝ち越し・負け越し、過去の銀・銅メダル、U15アジア/インターハイ/世界選手権の優勝、進路、金を取った年齢でセリフと称号が変わる。
- **金メダル後も続行できる**: 特別エンディングのあとに「現役を続ける / ここで引退する」を選べる。続けると36歳まで挑戦でき、2個目・3個目の金メダルもねらえる(36歳で取ったときは引退のみ)。
  金メダルの数で称号が変わる(2個: オリンピック連覇の王者 / 2度の金メダリスト、3個: 史上最強のレスラー)。
  標準的な遊び方で36歳まで続けた場合の金メダルの数: 0個 76% / 1個 19% / 2個 4% / 3個 0.5%。
