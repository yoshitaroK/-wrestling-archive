# レスリング人生 〜オリンピックへの道〜

`index.html` 1ファイルで動くスマホ向けの育成ゲームです(仕様は `wrestling-life-spec.md`)。
公開後のURL: https://japanwrestlingchannel.com/game/

## ファイル
- `index.html` … ゲーム本体。計算部分(`==LOGIC START==`〜`==LOGIC END==`)と画面部分に分けてあります。
- `sim.js` … バランス確認用の自動プレイ。`node game/sim.js 5000` で5000人ぶん遊んで金メダル率などを表示します。
- `wrestling-life-spec.md` … 仕様書。

## バランス(仕様書の初期案から変えたところ)
初期案のままだと、ふつうに遊ぶだけで24歳の金メダル率が約8割になり簡単すぎたため、
`index.html` の `BAL`(バランス調整用のつまみ)で次のように調整しました。

| つまみ | 初期案 | いま | 意味 |
|---|---|---|---|
| gainScale | 1.0 | 0.88 | 練習の上昇量の全体倍率 |
| capDiv | 150 | 120 | 伸びにくさ `1 − 現在値/capDiv` |
| declineSS | 1.5 | 4 | 31歳以降のスタミナ・スピードの衰え(毎年) |
| declineOther | 0 | 2 | 31歳以降のほかの3能力の衰え(毎年) |
| olyStep | 1.5 | 5.5 | オリンピックの相手が4年ごとに強くなる量 |
| trialsStep | 0 | 5 | 代表選考会の相手が4年ごとに強くなる量 |
| topBonus | 0 | 3 | 代表選考会とオリンピックの相手に足す強さ |

標準的な遊び方(疲労を管理しながら低い能力を伸ばし、大会前は休む)での結果(5000回):
金メダル率 約22%(24歳 3% / 28歳 14% / 32歳 5% / 36歳 ほぼ0%)。
(最初は47%だったが、遊んだ感想「もっと難しくていい」を受けて topBonus=3 を追加)
休まず練習し続けると 3% 前後まで下がります。

つまみは `node game/sim.js 3000 gainScale=0.9 olyStep=5` のように、ファイルを書き換えずに試せます。

## 仕様書と少し違うところ
- 世界選手権・オリンピックの決勝の相手はライバルではなく外国の「世界王者」(ライバルは日本人なので)。
- 「良い師匠」は出会ったその年(春・夏・秋の3回)の成長が×1.3。
- オリンピックで準決勝に負けると3位決定戦(勝てば銅、負ければ4位)。それより前に負けたらメダルなし。
- 生まれる子の性別は決めず「赤ちゃん」と表示しています。

## v2(大型アップデート)
- **試合を自分で戦う**: 試合は2ピリオド。ピリオドごとに作戦(攻め/カウンター/じっくり)を選ぶ。3すくみで、相手の型(攻め型/カウンター型/守り型)に合えば有利(`BAL.tactic`)。
  ライバルと王者は第1ピリオドが終わるまで型が分からない。第2ピリオドで作戦を変えてくる相手もいる(`BAL.styleSwitch`)。
- **同点はミニゲーム**: ゲージが金色の真ん中に来た瞬間に押すと、ラストポイントを取りやすい。
- **動く試合シーン**: 会場・マット・選手の絵はすべて SVG と CSS でその場で描いている(画像ファイルなし)。タックルや投げ、フォールが動き、得点が入る。高速/スキップあり。
- **効果音**: Web Audio でその場で合成(音声ファイルなし)。右上のボタンで消せる。
- **殿堂**: 最後まで生きた人生の記録を端末に保存してランキング表示。
- **実績**: 28個。条件を満たすと通知が出る。
- **結果カード**: エンディングで画像を作り、保存・シェアできる。戦闘力の歩みのグラフ、通算成績も出る。
- 主人公の絵は年齢で体が大きくなり、疲れると汗をかく。人生の進み具合(6〜36歳)とオリンピックの年が帯で見える。

難しさ(5000回の自動プレイ、`node game/sim.js 5000`):
| 練習 | 試合の作戦 | 金メダル率 |
|---|---|---|
| バランス良く・疲労管理 | 相手の型を読んで選ぶ | 約26% |
| バランス良く・疲労管理 | でたらめ(`play=random`) | 約12% |
| 休まず練習 | 読んで選ぶ | 約1% |

3連覇した人が4連覇できる確率は約1%(`legendBonus: 2`)。`topBonus` は 4.5。

## v2.5 見切りからの押し出し
- 鉄壁の見切りで相手の技をかわしたら、そのまま相手を場外に押し出して1点(最大2回)。
- そのぶん強くなったので、見切りの成功率の上限を下げた(`spGuardMax` 0.65→0.4)。見切りの金メダル率 約13%、必殺技なし 約7%(目標 12%±1 / 7%)。

## v2.4 難しさの調整(金メダル 約12% / 必殺技なし 約7%)
- 運営者の指定で、必殺技ありの金メダル率を約12%、なしを約7%にした。
  - 代表選考会とオリンピックの相手: `topBonus` 7→8
  - 必殺技の成功率に全体で `spMul: 0.5` をかけた(成功率はおおよそ2〜3割)。
  - 豪腕ぶっこ抜きは、失敗したときに返される確率を30%にした(成功率が下がって損な技にならないように)。
  - 3連覇からの4連覇は約1%のまま(`legendBonus` 1→3.5)。3連覇そのものは約1500人に1人。
| 必殺技 | 金メダル率(7000回) |
|---|---|
| 稲妻タックル / ぶっこ抜き / ローリング / 見切り | 約12% / 約13% / 約11% / 約13% |
| 使わない | 約7% |
| 全体(`node game/sim.js 6000`) | 約12%(24歳1% / 28歳8% / 32歳3%) |

## v2.3 回避の必殺技・必殺技の弱体化
- 必殺技に4つ目「🛡 鉄壁の見切り(回避型、メンタル)」を追加。使ったピリオドは、相手の得点を1回ずつ成功率で判定して、最大2回かわす。かわすと「見切ってかわした!」と出る。
- 「必殺技が強すぎる」という声を受けて弱くした。成功率を下げ(`BAL.spTackle` などで調整できる)、稲妻タックルの「勢いに乗る」効果をなくした。代表選考会とオリンピックの相手も少し弱くした(`topBonus` 9→7)。
| | 前(v2.2) | 今 |
|---|---|---|
| 必殺技を使う(第2ピリオド) | 約26〜30% | 約25〜29%(4種類) |
| 必殺技を使わない | 約5% | 約11% |
  必殺技は「あると有利」だが、なくても戦えるくらいにした。3連覇からの4連覇は約1%のまま。

## v2.2 必殺技
- 12歳の年のはじめに「得意技を決める」イベント。3種類から1つ選び、名前を付ける(10文字まで。空なら技の名前)。前の版のセーブで12歳を過ぎている人は、次の年のはじめに出る。
- 試合で1回だけ使える。作戦ボタンの上の「必殺技」をタップしてから作戦を選ぶと、そのピリオドの最初に打つ。カットインと効果音が出る。
| 種類 | 能力 | 成功したとき | 失敗したとき |
|---|---|---|---|
| ⚡ 稲妻タックル(確実型) | スピード | 2点+そのピリオドは勢いに乗って有利 | 失点なし |
| 💥 豪腕ぶっこ抜き(一発逆転型) | 筋力 | 4点 | 返されて相手に2点 |
| 🌪 無限ローリング(連続型) | 技術 | 2点、最大2連続 | 失点なし |
- 成功率は練習画面と試合画面に出る。実績を2個追加(必殺技を初めて決める / 30回決める)。結果カードとエンディングにも必殺技の成績が出る。
- 必殺技のぶん試合が有利になるので、代表選考会とオリンピックの相手を強くした(`topBonus` 4.5→9)。3連覇した人の4連覇(約1%)は `legendBonus` 2→1 で合わせた。
- 自動プレイ(`node game/sim.js 5000`、第2ピリオドで必殺技を使う): 金メダル率 約26%。種類ごとの金メダル率は 稲妻タックル約30% / ぶっこ抜き約29% / ローリング約28% でほぼ同じ。必殺技を一度も使わないと約5%。

## v2.1(遊んだ感想からの修正)
- 作戦の名前を「攻め / カウンター / 守り」にそろえた(前は自分の作戦が「じっくり」、相手の型が「守り型」で分かりにくかった)。じゃんけんは 攻め ▶ 守り ▶ カウンター ▶ 攻め。
- **テクニカルスペリオリティ**: 10点差がついた瞬間に試合終了(`TECH_GAP`)。全試合の約1割がこの決着になる。
- **得点の入り方を増やした**(`MOVES`): 1点=場外押し出し・アクティビティタイム、2点=バックポイント・片足タックル・がぶり返し・アンクルホールド・両足タックル・ローリング、4点=首投げ・持ち上げタックル・一本背負い、5点=スープレックス。技術が上がると使える技が増える。
- 3人の担当(ルール・遊びやすさ・品質)のレビューを反映: アクティビティタイムの文を「〇〇に1点! 相手が消極的」に、古いセーブで10点差のまま再開した試合の扱い、ボタンの説明の行ぞろえ など。
- 金メダル率は変わらず約25%(`node game/sim.js 4000`)。

## あとから追加したもの
- **U15アジア選手権**(15歳): 全国中学大会で優勝すると、同じ冬に出場できる。相手はアジアの国の架空の選手、全4試合、強さは全中+4。決勝の相手は「アジア王者」。
  標準的な遊び方だと、全中優勝 約56% → アジア優勝はそのうち約33%。
- **金メダルの特別エンディング**: 決勝の瞬間 → 表彰式 → ライバルの言葉 → 地元への凱旋 → その後と称号 → 成績まとめ、の順に「つぎへ」で進む。
  決勝のスコアや決まり方、ライバルとの勝ち越し・負け越し、過去の銀・銅メダル、U15アジア/インターハイ/世界選手権の優勝、進路、金を取った年齢でセリフと称号が変わる。
- **金メダル後も続行できる**: 特別エンディングのあとに「現役を続ける / ここで引退する」を選べる。続けると36歳まで挑戦でき、2個目・3個目の金メダルもねらえる(36歳で取ったときは引退のみ)。
  金メダルの数で称号が変わる(2個: オリンピック連覇の王者 / 2度の金メダリスト、3個: 史上最強のレスラー)。
  標準的な遊び方で36歳まで続けた場合の金メダルの数: 0個 76% / 1個 19% / 2個 4% / 3個 0.5%。
