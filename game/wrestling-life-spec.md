## 1. ゲームの概要
- タイトル案: 「レスリング人生 〜オリンピックへの道〜」
- 生まれた瞬間から始まり、オリンピックで金メダルを取るのがゴール。
- 毎年「練習メニューを3回選ぶ」→「年末の大会」を繰り返す育成シミュレーション。
- 35〜36歳までに金メダルを取れなければ引退エンディング。何度でも「生まれ変わって」遊べる。

## 2. 技術条件
- `index.html` 1ファイルで完結(HTML + CSS + JavaScript、ライブラリなし)。
- スマホ縦画面を最優先(幅360px前後でも崩れない)。タップで遊べること。
- セーブは `localStorage`。タイトルに「はじめから / つづきから」。
- ユーザー入力(選手名)は必ずエスケープして表示する。
- 見た目: 暗めの背景に赤と金のアクセント(道場・試合会場の雰囲気)。

## 3. 人生の流れ
| 年齢 | 段階 | 内容 |
|---|---|---|
| 0歳 | 誕生 | 出身(都道府県をランダム)と生まれつきの才能(5能力それぞれ★1〜3)を表示 |
| 0〜5歳 | 幼児 | 育て方を3択で1回選ぶ(外遊び→スタミナ/スピード、家族と組み合い→筋力/技術、本や音楽→メンタル)。終わると6歳へ |
| 6〜 | 毎年 | 年初イベント → 練習3回(春・夏・秋)→ 冬に大会 → 翌年へ |
| 8歳 | 固定イベント | レスリングとの出会い(読み物のみ) |
| 10歳 | 固定イベント | 宿命のライバル出現(名前をランダム生成) |
| 15歳 | 進路選択 | 強豪高校(成長×1.15、毎回の疲労+3)/ 地元の公立高校(成長×1.0、疲労−2) |
| 18歳 | 進路選択 | 強豪大学(×1.15、疲労+3)/ 実業団(×1.1、疲労0)/ 海外留学(×1.2、疲労+4、メンタル+5) |
| 24・28・32・36歳 | オリンピックイヤー | 代表選考会 → 勝てばオリンピック |
| 37歳 | 引退 | 金メダルなしならエンディング |

## 4. 能力と練習
- 能力5つ: 筋力(str)、スタミナ(sta)、技術(tec)、スピード(spd)、メンタル(men)。各0〜100。初期値は3〜8。
- 才能倍率: 能力ごとに0.85〜1.3(誕生時にランダム)。
- 疲労(0〜100)の状態も持つ。

練習メニュー(1回選ぶごとに1シーズン消費):
| 名前 | 上がる能力 | 疲労 | 備考 |
|---|---|---|---|
| 筋トレ | 筋力+8、スピード+1 | +14 | |
| 走り込み | スタミナ+8、スピード+1 | +12 | |
| 技の練習 | 技術+8 | +10 | |
| ダッシュ・敏捷 | スピード+8、技術+1 | +10 | |
| スパーリング | 技術+4、メンタル+5、筋力+1 | +18 | ケガ率+8% |
| メンタル修行 | メンタル+8 | +4 | |
| 休養 | なし | −40 | |

上昇量の計算(初期案):
`基本値 × 才能倍率 × 年齢係数 × 疲労係数 × 進路係数 × 師匠バフ × (1 − 現在値/150)`
- 年齢係数: 〜7歳 0.7 / 8〜11歳 0.9 / 12〜17歳 1.15 / 18〜26歳 1.0 / 27〜30歳 0.85 / 31歳〜 0.7
- 疲労係数: 疲労65超 0.8 / 85超 0.5
- 31歳以降は年末にスタミナとスピードが−1.5ずつ衰える。
- 年末に疲労−10。

## 5. ケガ
- 練習のたびに、ケガ率 = (スパーリングなら0.08) + max(0, 疲労−80)/100 で判定。
- ケガをしたら残りの練習は自動でリハビリになり、その年の大会は欠場。翌年に疲労は30以下から再開。
- 「大会前の第3シーズンは休養で疲労を抜く」という駆け引きが生まれる設計にする。

## 6. 試合
- 戦闘力 = (筋力 + スタミナ×0.8 + 技術×1.3 + スピード + メンタル×0.9) ÷ 5
- 試合時の戦闘力 = 戦闘力 × (1 − max(0, 疲労−50)/150)
- 1試合は2ピリオド。各ピリオドの得点 = `max(0, round(2 ± 戦闘力差/7 + ランダム(−2.5〜2.5)))`
- 合計点が高い方が勝ち。同点ならメンタルを含む乱数で決める。
- 戦闘力差が20超なら20%でフォール勝ち(逆も同様)。
- 得点シーンには、技術値で解放される得意技名を使う: 15=片足タックル / 35=ダブルレッグタックル / 55=ローリング / 75=ガットレンチ / 90=スープレックス
- 試合後、勝ちでメンタル+0.6、負けで+0.3。
- 画面では試合を1つずつ「つぎへ」で見せる(ピリオドごとの得点、決め技、勝敗)。

## 7. 大会表(年齢 → 名前 / 相手の強さ / ラウンド数)
- 10: 地区少年大会 / 12 / 2
- 11: 県少年大会 / 17 / 2
- 12: 全国少年大会 / 22 / 3
- 13: 中学地区大会 / 27 / 2
- 14: 中学県大会 / 31 / 2
- 15: 全国中学大会 / 36 / 3
- 16: 高校新人大会 / 41 / 3
- 17: インターハイ / 47 / 4
- 18: 全国高校選抜 / 52 / 4
- 19: インカレ / 56 / 4
- 20: 全日本学生選手権 / 59 / 4
- 21: 全日本選抜 / 62 / 4
- 22〜23: 全日本選手権 / 64〜66 / 4(優勝すると同年に世界選手権へ)
- 24歳以降(オリンピックイヤー以外): 全日本選手権 / 65+min(5, 年齢−24) / 4 → 優勝で世界選手権(相手の強さ+4)
- 24・28・32・36歳: オリンピック代表選考会(強さ67、3ラウンド)。優勝すればオリンピック(強さ 68+(年齢−24)/4×1.5、4ラウンド)
- 10歳未満は大会なし。

相手の強さ: 通常ラウンド = `強さ − (総ラウンド − 現ラウンド)×3 ± 3`
決勝(3ラウンド以上の大会)は必ずライバルと対戦: `強さ + 4 ± 2〜3`
- ライバルとの通算成績(勝ち/負け)を記録して表示する。
- オリンピック準決勝で負けたら銅メダル戦(相手は強さ−3)。決勝負けは銀メダル、勝ちで金メダル=ゲームクリア。
- 世界選手権・オリンピックの相手は外国人風の架空の名前(名+姓+国名)をランダム生成。実在の選手名は使わない。

## 8. ランダムイベント(8歳以降、固定イベントのない年に35%)
- 良い師匠との出会い(翌年の成長×1.3)
- 風邪(疲労+25)
- 仲間と特訓(技術+3、メンタル+2)
- おいしいごはん(筋力+2、疲労−10)
- オリンピックをテレビで観る(6〜13歳限定、メンタル+3)
- スランプ(12歳以上、メンタル−3)
- 新トレーニング法(スピード+3)

## 9. 画面構成
1. タイトル(名前入力、はじめから/つづきから)
2. 誕生(出身と才能の★表示)
3. 幼少期の選択
4. 年初イベント(読み物 or 選択肢)
5. 練習選択(ヘッダーに名前・年齢・段階、能力バー5本と才能★、疲労バー、今年の大会名、直前の練習結果メッセージ)
6. 大会(試合を1つずつ表示 → 結果まとめ)
7. エンディング(金メダル or 引退。通算優勝歴・メダル・ライバルとの対戦成績・「生まれ変わる」ボタン)

## 10. バランスの目標(作った後に自動プレイで確認してほしい)
- 「疲労管理をしながらバランス良く育てる」標準的な遊び方で、24歳での金メダル率は低め(1割前後)、28〜32歳で届く人が多い、全体で4〜5割くらいが金メダル、を目安に。
- 簡単すぎ/難しすぎなら、大会表の相手の強さと上昇量の式を調整する。
- 計算ロジックは画面処理と分けて書き、Node.jsで何千回も自動プレイして確認できる形にする。
