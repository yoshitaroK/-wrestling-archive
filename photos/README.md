# 写真フォルダ

大会ページ・開催回ページに載せる写真(JPG / PNG / WebP)をここに入れます。
入れただけでは表示されません。`photos.json` に1枚ずつ書いたものだけが表示されます。

- このフォルダの写真は、リポジトリが公開のため **誰でも見られます**。掲載してよいか確認できていない写真(特に未成年が写っている写真)はアップロードしないでください。
- スマホで撮った写真には撮影場所(GPS)が入っていることがあります。アップロード前に消してください。
- ファイル名は半角の英数字とハイフンにしてください(例: `interhigh-2024-01.jpg`)。

このフォルダの `index.html` と、その下の大会名のフォルダ(例: `intercollegiate/2026/index.html`)は、写真ページ(https://japanwrestlingchannel.com/photos/)として自動で作られるファイルです。手で編集・削除しないでください(消しても次の自動更新で作り直されます)。
