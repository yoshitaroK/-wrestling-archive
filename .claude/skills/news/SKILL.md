# /news — 大会結果のニュースを作って PR を出す

運営者は初心者です。説明・PR はすべて日本語で書きます。**マージは絶対にしない**(運営者が読んでからマージします)。

## 1. 新しい結果を探す

1. レスリング・スピリッツ(https://wrestling-spirits.jp/)のトップページから、直近3日の記事を見る。国内大会の結果がまとまった記事(「《速報》〇〇・第N日」、「〜が優勝…〇〇」など、決勝の勝敗とスコア・準決勝・5位が載っているもの)を探す。リンクだけの「《結果速報》」「《ネット中継》」、海外大会、少年少女・キッズ大会は対象外。
   - 取得は `curl -sSL -A "Mozilla/5.0"`。つながらないときは 2・4・8 秒おいて3回まで試す。kirokukensaku.net など、この環境から開けないサイトは使わない。
2. もう記事にしたものは除く:`news.json` の各記事の `sources` に同じ URL があるもの、`claude/news-auto-` で始まるブランチ・開いている PR に同じ大会・同じ日のものがあるもの。
3. 新しいものがなければ、何も変えずに終わる(PR も通知も出さない)。

## 2. 結果を入れる

1. `data.json` の `events` と `page_slugs.json` から、その大会の開催回 ID(`wre-YYYY-…`)を探す。見つからない・あいまいなときは、結果欄は作らず記事だけにし、PR の説明に「開催回が分からなかった」と書く。
2. 開催回が分かれば、`event_results.csv` に1位・2位・3位(準決勝で負けた2人)・5位(4人)を足す(列:開催回ID,種別,階級,成績,氏名,都道府県,所属,出典URL)。種別は「成年男子フリースタイル」「女子」「少年男子グレコローマン」など記事の書き方に合わせる。改行コード(CRLF)と文字コード(BOM 付き UTF-8)はそのままにする。
3. 元の記事の打ち間違い(かっこの抜けなど)は直して入れ、PR の説明に書く。

## 3. 記事を書く

- `articles/<slug>.md` に本文、`news.json` の `articles` の先頭に1件足す。slug は `YYYY-<大会の英字ID>-dayN` などの半角英小文字。`date` は記事を書いた日。`sources` に使った記事の URL の配列を入れる。`event_id`・`category`(大会名)・`lead`(1〜2文)・`tags`(大会と主な選手、5つまで)も書く。
- 書き方は `articles/2026-kokutai-day2.md` を手本にする:
  - 最初の段落:大会名・日付・会場・その日に決勝があった階級。
  - 小見出しごとに、優勝者・決勝の相手・スコアを書く。
  - 選手の過去の成績は、このサイトの選手データ(`players.csv`・`player_results.csv`)にあるものだけを使う。
  - 最後に決勝結果の表、全結果は大会ページにあること、出典のリンク。
  - 選手ページがある人は `[[p-xxxxxx|名前]]`、大会ページは `[[event:開催回ID|文字]]` でリンクする。選手は `players.py` の `same_name` と同じく、髙/高・德/徳などの違いを無視して探す。同じ名前が2人いるときはリンクしない。
- **書かないこと**:元の記事の文章をなぞること(使うのは誰が勝ったか・スコアなどの事実だけ。文は一から書く)、見ていない試合の様子、選手のコメント、データにない経歴。
- **高校生などの未成年**:名前・学校・結果は書いてよい。ただし一人を大きく取り上げたり、見出しにしたりはしない。選手ページへのリンクはしない。
- 見出しは事実だけで 40 字くらいまで。

## 4. 確かめて PR を出す

1. `python3 build_pages.py` を実行し、エラーがないこと、`build_report.json` の `photos` の `errors`、`news` の `errors`・`warnings` が空なことを確かめる。
2. 記事のページ(`/news/<slug>/`)を `npx http-server` と Playwright(`/opt/pw-browsers/chromium`)で開き、パソコン(1280px)とスマートフォン(390px)のスクリーンショットを撮る。Artifact が使えればまとめて公開し、リンクを PR に書く。
3. PR に入れるのは元のファイル(`event_results.csv`・`news.json`・`articles/`、必要なら `players.csv`・`player_results.csv`)だけ。作られるファイル(`news/`・`events/`・`en/`・`players/`・`data.json`・`build_report.json`・`sitemap.xml`・`assets/site.css` など)は入れない。
4. ブランチは `claude/news-auto-<slug>`。PR の題名は「ニュース:<見出し>」。説明に、記事の要約、使った出典、結果欄に足した件数、選手ページにリンクした人数、直した打ち間違い、確かめたことを書き、最後にマージの手順(「Merge pull request」→「Confirm merge」→ Actions タブで「Update wrestling archive data」が緑になるのを待つ)を書く。
5. 運営者に、PR のリンクと見出しを短く知らせる。
