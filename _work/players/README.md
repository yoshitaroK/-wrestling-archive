# 選手ページの準備(作業用・サイトには公開されません)

`_` で始まるフォルダは GitHub Pages で公開されないので、ここに作業用のファイルを置いています。

## 決まっていること(/grill-me で決定)
- 選手の一覧は、日本レスリング協会の大会ページにある「入賞者一覧」の PDF から作る
- 対象は大人の大会だけ:天皇杯・明治杯・全日本社会人・全国社会人オープン・大学の大会(インカレ・全日本大学・全日本大学グレコ・東日本学生・西日本学生)・国際大会
- 高校・中学・少年少女・年代別の大会からは名前を拾わない。大人の大会でも、所属が高校・中学・少年団などの人は表に入れない(「〇〇高校教員」のような大人は残す)
- 「公開」:確認メモがない人は「はい」、メモがある人は「いいえ」(運営者が確かめた人から「はい」に変える)
- 選手ページのアドレスは表の選手ID(例:`/players/p-b4370b/`)。名前のローマ字にはしない
- 選手ページの下に「掲載の取りやめはお問い合わせから」と書く。連絡が来たら players.csv の「公開」を「いいえ」にする
- 東日本学生の「新人戦」の部は、成績に「新人戦」と書いて区別する

## ファイル
| ファイル | 中身 |
|---|---|
| `players_candidates.csv` | 選手の候補(763人)。players.csv と同じ列に、確認用の「入賞回数・最高順位・主な成績・確認メモ」を足したもの |
| `player_results_candidates.csv` | 成績(1651件)。player_results.csv と同じ列 |
| `jwf_index.json` | 調べた大会と、入賞者一覧の PDF のアドレス |
| `fetch_pdfs.py` | PDF を `jwf/` に取ってくる(協会のサイトの許可が環境のネットワーク設定に必要:`www.japan-wrestling.jp`) |
| `parse_winners.py` | PDF から階級・順位・氏名・所属を取り出す(文字の位置で名前と所属を対応づける) |
| `build_candidates.py` | 上の2つの CSV を作る |
| `make_romaji.py` | 英語版の選手名(ローマ字)の下書き `romaji_auto.csv` を機械で作る(pykakasi が必要。毎日の自動更新では使わない) |
| `romaji_fix.tsv` | 機械のローマ字を直したもの。3列目が「はい」の人は、公の英語表記と一致を確かめた人 |
| `kana_entries.py` | 大会のエントリーリスト(jwf_index.json の entry_lists)から読みがなを取り出して `kana_entries.csv` を作る。英語名はこの読みから作る |
| `uww_results.py` | オリンピック・世界選手権・U23世界選手権の成績を UWW の結果の冊子から取り、player_results.csv に足す |
| `make_players_csv.py` | 上の表から、リポジトリの一番上の `players.csv` / `player_results.csv` を作る。運営者が変えた「公開」「未成年」「ローマ字」「ローマ字確認」は残す |

作り直すとき:`python3 fetch_pdfs.py` → `python3 build_candidates.py` → `python3 kana_entries.py` → `python3 make_romaji.py` → `python3 make_players_csv.py`

## 明治杯 2025(文字の対応表も、フォントの cmap も無い PDF)
- 入賞者一覧の PDF は、フォント(MS Pゴシック)の字の一部だけを入れた形で、文字の対応表もフォントの cmap も無い。そのままでは文字が読めない
- 同じ大会の階級ごとのトーナメント表・組み合わせの PDF(60個。`jwf_index.json` の `glyph_refs`)は同じフォントで、対応表がある。
  同じフォントの同じ字は輪郭の座標が同じなので、`fix_glyphs.py` が jwf/ のほかの PDF の字形と照らし合わせて、対応表を作る(`"fix_glyphs": true`。`fetch_pdfs.py` が取ってきたあとに動かす)
- 参照の PDF どうしで同じ形に別の字が付いているものは使わない。分からない字は「〓」にして、`build_candidates.py` はその行を使わない
- 確かめたこと:読み取った 120人の名前は全員、トーナメント表(対応表あり)にも出ている。30階級の優勝者は、字の違い(徳/德)を除いて歴代記録と同じ
- 「3位(4位)」の欄のかっこ付きの名前は、2024・2026年と同じく 3位 として入れている

## 斜字体・網掛けで順位を分けている一覧(2018年天皇杯・2019年明治杯・2019年天皇杯)
- 一覧の下に「斜字体は4位」「網掛けは各順位1名となります。4位/5位/6位/7位」と書かれた一覧は、見出しの「3位」「5位」の欄に入っていても、印の付いた人は1人ずつの順位(総当たりの階級)
- `parse_winners.marks()` が、注記のある一覧だけ、斜めに傾けた字(斜字体)と薄い灰色で塗った四角(網掛け)の場所を PDF から取る(pypdf が必要)。印の付いた人は「前の欄の順位の次の数字」にする
  (例:2019年天皇杯 女子65kg は 3位・4位・5位・6位・7位)
- 2018年天皇杯の女子は、見出しが「1位・2位・3位(2人分)・4位」。3位が1人の階級は、空いた欄の右に4位の人がいる。
  1行だけでは欄の位置が分からないので、同じ表のほかの行も合わせた欄の位置で見出しと合わせる
- 確かめたこと:PDF を画像にして、印の付いた人がすべて合っていることを目で見て確かめた

## SNS 用画像(og_cards.py)

選手ページの URL を X・LINE などに貼ったときに出る画像。運営者と決めたこと(2026-10-06):

- 紺と赤の地に文字だけ(1200×630)。名前(日本語版は漢字とふりがな、英語版はローマ字)・所属・代表の印・大会成績・件数・サイト名

- 公開している選手全員分。日本語版 `assets/og/players/<ID>.png`、英語版 `<ID>-en.png`

- 見た目を変えたら `og_cards.py` の `VERSION` を上げる(全員分が作り直される)
- フォントは `fonts/` の Noto Sans JP(SIL Open Font License。`fonts/OFL.txt`)
- 画像に載せる短い大会名は `og_cards.py` の `SHORT`。新しい大会が増えて名前が切れるようなら足す

## 2014〜2023年の成績(#54)

- 出典は協会の以前のサイト(wrestling-spirits.jp)の大会結果記事に付いている入賞者一覧(ichiran)の PDF。`jwf_index.json` の `source` が「日本レスリング協会の以前のサイト…」の行
- 1大会ずつ足す。済んだもの:天皇杯 2020〜2023、明治杯 2021〜2023、全日本大学 2020〜2021、全日本大学グレコ 2021〜2023、全日本社会人 2022〜2023、インカレ 2022〜2023、明治杯 2014〜2018・天皇杯 2014〜2019、全日本大学グレコ 2020、インカレ 2021、明治杯 2019(全日本大学 2022・2023 は PDF が画像で読めない)
- **2014〜2019年の PDF**(明治杯・天皇杯)は、名前が「高 橋 侑 希」のように1文字ずつ空けて書かれている。`parse_winners.py` の `spaced_names` で読む。
  1人分の欄は4文字分の幅で、左の2文字分が姓・右の2文字分が名(3文字の姓・名は2文字分に詰めてある)なので、文字の位置で姓と名を分ける。
  pdftotext が隣の人の文字とつなげて1語にすることがあるので、1文字ずつに分けてから欄に入れる。
  順位は見出し(「3位」は2人分、「5位」は2人分や4人分の欄の真ん中にある)の位置で決め、数字の並び(3位が2人なら次は5位)が合わない行や、読み取りに自信が無い行は使わない。
  所属は1語ずつ、いちばん近い人の欄に入れる(隣の人の所属とくっつかないように)
- 2014・2015年と2016年明治杯の一覧は、3位の次が「4位」と書かれている。一覧のとおり「4位」として入れる
- 2015年明治杯の女子の一覧は画像なので読めない。2018年天皇杯の女子(ichiranFe.pdf と ichiranFF.pdf の女子の部分)は、見出しの「3位」「4位」が欄とずれていて順位が決められないので使わない
- 2017年明治杯グレコローマン85kg級は、一覧と大会記事では塩川貫太が優勝、歴代記録は世界選手権代表決定プレーオフに勝った松本篤史になっている。サイトは一覧のとおり
- 名前に空白が無い人・1文字ずつ空けた名前しか無い人は、「姓と名の区切りが分からない」の確認メモを付けて公開しない
- 明治杯 2019 の PDF は文字の対応表(ToUnicode)が空で、そのままでは「階級」が「㝵⣭」のように出る。`jwf_index.json` に `"fix_tounicode": true` を付けると、
  `fetch_pdfs.py` が取ってきたあとに `fix_tounicode.py` で、PDF に埋め込まれたフォント自身の対応表から作り直す(pypdf と fontTools が要る:`pip install pypdf fonttools`)。
