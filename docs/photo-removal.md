# 写真の取り下げと、変更履歴からの削除

Issue #19 の作業用の説明書です。「写っている本人や保護者から、写真を消してほしいと言われた」ときの手順を、軽いものから順に書いています。

## 0. どこに写真が残っているか

| 場所 | 中身 | 消し方 |
|---|---|---|
| サイト(`assets/photos/`) | サイト用の縮小版(1600px)とサムネイル(480px) | 手順1で自動で消える |
| Cloudflare のキャッシュ | 少し前の縮小版 | 手順1のあと「Purge Everything」 |
| GitHub の変更履歴 | 過去に入れたファイル。**最初にアップロードしたインカレ2026の元の写真57枚(`photos/DSC…`)は履歴に残っている**。2026年10月以降に Claude が取り込んだ写真は、元の写真を履歴に入れていない | 手順3(大がかり) |
| Google の画像検索 | 検索結果の画像 | 手順2 |

## 1. サイトから取り下げる(ふだんはこれだけ)

1. GitHub でリポジトリを開き、`photos.json` を開いて、右上のえんぴつのマーク(Edit)を押します。
2. 消したい写真の行を探します。写真ページで写真を拡大したときの画像のアドレス(`/assets/photos/xxxxxxxxxxxx.jpg`)は、`assets/photos/manifest.json` で元のファイル名と対応しています。わからなければ、写真ページのアドレスと「何枚目か」を Claude に伝えれば探します。
3. その写真の `"hidden": false` を `"hidden": true` に書き換えて、「Commit changes」を押します。
4. 「Actions」タブ →「Update wrestling archive data」→「Run workflow」で手動実行します(翌朝6時の自動更新を待ってもかまいません)。
5. 終わったら Cloudflare で「Purge Everything」を押します。
6. 依頼してくれた人に、取り下げたことを返信します。

これで、サイトからも `assets/photos/` からも縮小版が消えます。

## 2. Google の検索結果から消す

サイトから消したあとも、しばらく Google の画像検索に残ることがあります。
Google Search Console(Issue #21 で登録)の「削除」→「新しいリクエスト」で、画像のアドレスを入れると、検索結果から一時的に隠せます。

## 3. GitHub の変更履歴からも消す(本当に必要なときだけ)

リポジトリは公開されているので、変更履歴を見れば過去のファイルを取り出せます。
本人の強い希望があるときや、元の写真に撮影場所などの情報が残っていたときは、履歴からも消します。

**影響が大きい作業なので、必ず Claude と相談してから行います。**

- 履歴を書き換えるので、作業中のPRやブランチがすべて作り直しになります。マージ待ちのPRを片付けてから行います。
- 毎日の自動更新(Actions)は、作業のあいだ止めます。
- GitHub の「main」に強制的に書き込む(force push)必要があります。運営者の許可を得てから、Claude が作業します。

### 作業の流れ(Claude が行う)

1. マージ待ちのPRを片付け、Actions の自動更新を一時停止する。
2. `git filter-repo` で、該当するファイルを全履歴から取り除く。
3. 取り除けたことを確かめてから、main に force push する。
4. 運営者が GitHub サポート(https://support.github.com/ )に「Removing sensitive data」として連絡する。古いPRの中やキャッシュに残った表示を消してもらうため。リポジトリ名と、消したファイルの名前を伝える。
5. 自動更新を再開し、サイトが正しく表示されるか確認する。

GitHub の公式の説明:「リポジトリからの機微なデータの削除」
https://docs.github.com/ja/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository

## 4. これから写真を追加するときの注意

- 元の写真は、できるだけ GitHub に上げずに Claude に取り込んでもらう(Google フォトのアルバムから取り込めば、元の写真は履歴に残らない)。
- 自分でアップロードするときは、撮影場所などの情報を消してから上げる(Windows:写真を右クリック →「プロパティ」→「詳細」→「プロパティや個人情報を削除」)。
